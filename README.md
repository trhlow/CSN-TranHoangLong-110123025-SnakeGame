# Snake Game - Multiplayer

Unity 2D Snake Game với hệ thống customization.

## Features
- Single Player mode
- VS AI mode  
- Customizable snake colors
- High score system
- Localization (Vietnamese/English)

## How to Play
- WASD: Player 1 movement
- ESC: Pause game
